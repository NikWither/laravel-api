GET http://127.0.0.1:8000/api/v1/lessons - получение всех уроков

GET http://127.0.0.1:8000/api/v1/lessons?price_min=1000&price_max=1200 - получение уроков в ценовом диапазоне 1000 - 1200 руб, можно использовать по одному параметру 

GET http://127.0.0.1:8000/api/v1/lessons?subject_id=2 - получение уроков по второму предмету

другие параметры для фильтрации уроков

isPaid - boolean, оплачен/неоплачен 
isPassed - boolean, прошло/отмена, в будущем видимо добавлю еще один параметр, отмена по собственному желанию

GET http://127.0.0.1:8000/api/v1/lessons/3 - получение урока с id=3

PUT http://127.0.0.1:8000/api/v1/lessons/18?price=800 - изменение цены у урока 18 (изменение вроде не на все параметры добавил)

POST  http://127.0.0.1:8000//api/v1/lessons?subject_id=2&price=300 - создание урока с предметом по айди 2 и ценой 300 (цена и айди урока обязательные параметры)
